Todo lo que necesitas para email marketing

Ocho módulos completamente integrados, sin plugins adicionales ni suscripciones externas.

👥

Gestión de contactos

Importa vía CSV, edita campos personalizados, consulta el historial completo de actividad y estados: subscribed, pending, unsubscribed, bounced.

📨

Campañas HTML

Editor HTML completo con vista previa, merge tags {{first_name}}, programación y envío por lotes para no saturar el SMTP.

🏷️

Listas y etiquetas

Segmenta tus contactos con listas de correo y etiquetas de clasificación. Envía campañas a audiencias precisas.

⚙️

Automatizaciones Pro

Flujos disparados por eventos. Pasos de tipo: email, espera, asignar tag, quitar tag, condición. Se ejecutan vía WP Cron cada 5 minutos.

📝

Formularios de suscripción

Shortcode [mrme_form id="X"] con campos configurables, doble opt-in y redirección personalizable.

📊

Reportes y analítica

Seguimiento de aperturas, clics, bajas y rebotes. Logs de envío detallados por campaña y contacto, exportables.

🔗

REST API

8 endpoints bajo mrme/v1/ para contactos, listas, campañas y formularios. Autenticación por usuario admin o header X-MRME-Key.

📮

SMTP personalizado

Elige entre wp_mail nativo, SMTP propio con PHPMailer, o Mailgun (plan Pro). Configurable desde el panel de admin sin tocar código.
