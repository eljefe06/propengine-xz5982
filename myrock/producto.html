Funcionalidades

Todo lo que necesitas
para hacer email marketing

Gestión de contactos

Importa desde CSV, segmenta por lista o etiqueta, y administra estados: suscrito, desuscrito, pendiente, rebotado. Perfil completo por contacto con historial de actividad.

Campañas HTML

Editor visual con soporte HTML completo. Personalización con merge tags: {{first_name}}, {{email}}, {{unsubscribe_url}}. Envío inmediato o programado.

Listas y etiquetas

Organiza contactos en múltiples listas. Agrega etiquetas para segmentación avanzada. Envía campañas a listas específicas o cruza filtros para precisión total.

Automatizaciones

Flujos automáticos activados por eventos: suscripción, clic en enlace, fecha específica o cambio de etiqueta. Secuencias de bienvenida, seguimiento y reactivación.

Formularios de suscripción

Crea formularios con el shortcode [mrme_form id="1"] e insértalos en cualquier página, entrada o widget. Double opt-in opcional con email de confirmación personalizable.

Reportes y analítica

Métricas en tiempo real por campaña: aperturas, clics, rebotes, cancelaciones. Log completo por contacto para ver su historial de interacción y depurar problemas de entrega.

REST API

Endpoints JSON documentados para integrar con tu CRM, e-commerce o sistema propio. Suscribe contactos, dispara campañas y consulta métricas desde cualquier aplicación externa.

SMTP personalizado

Conecta tu propio servidor SMTP (host, puerto, autenticación, encriptación). Compatible con cualquier proveedor. Prueba de envío directo desde el panel de configuración.
